In the SolidWorks folder, GEMINI-00-00-00.SLDASM is the master file that should be opened.

Getting around:

Final reports ("GEMINI-Fall_JP_CORRECTED.pdf" and "WilliamLiMAE399Spring2026Report_File.pdf") and PDR ("Fall 2025 GEMINI PDR.pdf") can be found in "GEMINI-Documents"

GEMINI-MATLAB contains the data processing file for GEMINI data: "GEMINIDataPipeline.m"

GEMINI-SIMION contains all the relevant SIMION files for the GEMINI Instrument

GEMINI-Solidworks contains all the necessary CAD files for GEMINI. There are some extraneous files for fasteners and old parts that were not used in the final version.

GEMINI-Drawings contains PDFs of the engineering drawings that were used to manufacture GEMINI.

In "GEMINI-Data", "GEMINI_FirstLightTestPlan.xlsx" contains the test record of two days of GEMINI data collection (configuration of the instrument, beam, notes, etc.). The gain curve file is "MCP Gain Curve Table.docx" found in "JP_Day1_Results" -> "William's GEMINI"

In "GEMINI-Data", "JP_Testing_FullDay1" and "JP_Testing_FullDay1" contain a folder with .csv files from the MCP that should be pointed to in MATLAB for processing. They also contain a folder with the .png output graphs from running the "GEMINIDataPipeline.m" Matlab file.
